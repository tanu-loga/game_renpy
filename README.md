# Another Summer
## What is this?
  A visual novel made in Ren'Py! This is based on The Summer Hikaru Died, which is an anime and manga.       
  ### What's a visual novel?          
    A novel which is visualised...           
    Just kidding, it's an interactive game where you can take choices and the story often shows different dialogue based on it. There might be different endings as well!          
  ### What is the game about?           
    You speak with Hikaru.. But at what cost? This is a slice-of-life with some horror elements in it.            
##What's used?              
  Engine- Ren'Py              
  Some art assets- Me            
  Rest of art assets- Official posters and images from The Summer Hikaru Died (to get more info, check the game               
  Music- Sourced from Audio Library and originally composed by Scott Buckley under Creative Commons           
## How do I play this?                                  
  Go to https://tanulogan.itch.io/another-summer                                                  
  Done? Next, click Start and then enjoy! Click the text box to move onto the next dialogue. Choose one of the options given to move onto the next part if shown.
